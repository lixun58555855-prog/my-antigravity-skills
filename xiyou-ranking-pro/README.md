# 西柚高精度排名监控 (Xiyou Ranking Pro)

这是一个专为 Antigravity 打造的高阶自动化 Skill（技能），它允许你通过自然语言快速查询亚马逊指定站点的 24 小时 SP 及自然排名，并由系统自动渲染出“全节点精准打标”的高精度可视化图表。

## 📥 安装步骤 (任意电脑)

1. 将当前这个名为 `xiyou-ranking-pro` 的文件夹完整复制。
2. 在你的目标电脑上，打开你正在使用的项目代码库目录，或者打开全局配置目录。
   - **项目级安装**：将其放在项目根目录的 `.agents/skills/` 文件夹下。
   - **全局安装 (推荐)**：将其放在你用户目录下的 `~/.gemini/config/skills/` 文件夹下。
3. 重新启动或在聊天框中唤醒你的 Antigravity 智能体即可。

## 🚀 使用方法

直接在对话框中发送以下格式的指令：
> “查一下美国站 B0XXXXXX 在 clock 的排名”
> “B083Y4766W dementia clock”

AI 会自动接管，请求 西柚MCP 数据，读取本文件夹内的 `templates/chart.html` 进行高精度 SVG 绘图，并返回直观的卡片。
